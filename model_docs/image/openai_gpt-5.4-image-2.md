## Capabilities

**Text-to-image (t2i) + Image-to-image (i2i)**

Combines GPT-5.4's reasoning capabilities with "state-of-the-art image generation
capabilities from GPT Image 2," supporting multimodal workflows that integrate
text processing and visual generation.

"Enables rich multimodal workflows, allowing users to seamlessly move between
reasoning, coding, and visual generation within the same interaction."

## Intended Use Cases

- Multimodal reasoning tasks requiring integration of text and image generation
- Coding assistance combined with visual output
- Complex workflows blending multiple modality types
- Editing existing images with reasoned prompts
